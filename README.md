# Quick-Bite-Food-Ordering-App



Quick Bit is a food ordering application that provides a seamless experience for users to browse menus, add items to the cart, and place orders quickly. This application is built using Spring Boot for the backend and React.js for the frontend.


# Features : 

Browse restaurants and food menu with food items

Add items to a cart

Place an order 

Backend RESTful API with Spring Boot

Interactive frontend using React.js

Integration with database for order persistence



# Requirements

Before you begin, ensure you have the following installed on your system:

Java Development Kit (JDK) 17 or above

Node.js (v16.x or above) and npm

Maven for building the backend

MySQL or any supported database



# Installation

1. Clone the Repository : 

git clone https://github.com/Ankit9767/Book-My-Show-Clone.git

2. Backend Setup (Spring Boot)

    1. Navigate to the backend folder : cd Quick-Bite

    2. Configure the database : ==> Open the application.properties in the src/main/resources folder. ==> Update the database URL, username, and password.
    
    3. Build and run the backend server : mvn clean install ==> mvn spring-boot:run

    By default, the server will run on http://localhost:8080

3. Frontend Setup (React.js) 

    1. Navigate to the frontend folder : cd Quick-Bite-frontend
    
    2. Install dependencies : npm install 
    
    3. Start the React development server : npm start

    By default, the React app will run on http://localhost:3000.




# Running the Application

1. Ensure the backend server is running (http://localhost:8080).

2. Start the frontend server (http://localhost:3000).

3. Open your browser and navigate to http://localhost:3000 to access the Quick Bit      application.
